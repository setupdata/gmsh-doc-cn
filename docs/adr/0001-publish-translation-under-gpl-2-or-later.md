# 中文译本按 GPL-2.0-or-later 发布

项目决定将 Gmsh 中文翻译源文件及由其生成的中文页面按 GPL-2.0-or-later 公开发布，保留上游版权声明、完整英文许可证、修改说明和修改日期，并公开生成中文页面所对应的翻译源文件。本项目自行编写且不含上游内容的脚本和样式可以继续使用仓库现有的 MIT 许可证。

这项决定依据 Gmsh 随附的 `LICENSE.txt` 将 Gmsh 置于 GPL 2.0 或更高版本之下，且 GPL v2 第 0 条将翻译列为修改。与此同时，`gmsh.texi` 的手册标题页另有只明确允许逐字复制的声明。本记录保存项目采用的许可解释，并不表示该解释已经得到 Gmsh 版权方确认；如果版权方给出不同说明，应重新审议本决定。
