| 内容 | 许可或处理方式 |
| --- | --- |
| Gmsh 上游 Texinfo、示例、图片、英文许可证、CREDITS 和英文对照页 | 保留上游版权及许可原文；Gmsh 软件为 GPL-2.0-or-later，并带 Gmsh 特别链接例外，全文见 `LICENSES/Gmsh-license.txt`；本项目不重新许可 |
| POT、包含大段上游英文的测试夹具 | 保留来源，按适用的上游条款处理 |
| 中文 PO、中文 Texinfo、基准参考译文和中文页面 | 本项目决定按 GPL-2.0-or-later 发布；手册标题页“逐字复制”条款与翻译的关系仍未获版权方确认 |
| 本项目自行编写且不含上游正文或译文的 Python 脚本、提示词、Schema、审校元数据、站点外壳和样式 | MIT，见仓库根目录 `LICENSE` |
| 混合文件 | 包含上游正文时保留上游条款；包含中文译文时按 GPL-2.0-or-later，不能只套用根目录 MIT |
| 第三方组件和随上游 CREDITS 收录的内容 | 按各自许可证处理；本矩阵不改变第三方许可 |

Gmsh 的特别链接例外没有标准 SPDX exception 标识。本项目使用文字 `GPL-2.0-or-later + Gmsh-specific linking exception`，不伪造 `WITH` 标识。本文件只说明仓库采用的边界，不构成法律意见。
